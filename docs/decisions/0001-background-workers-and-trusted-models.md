# ADR-0001：后台推理与可信模型边界

- 状态：已采用
- 日期：2026-08-21

## 背景

YOLO 推理在 Qt 主线程执行时会阻塞事件循环，视频、摄像头和导出还可能并发访问同一模型实例。PyTorch `.pt` 文件也不应被当作普通无害数据。

## 决策

1. 图片、批量、视频预览和视频导出均使用 `QThread`。
2. 每个工作线程在自己的线程内创建并独占 YOLO 实例，不在线程间共享。
3. 启动前和工作线程加载前都核对模型 SHA-256 和类别映射。
4. 停止使用协作式事件；窗口只在所有工作线程确认退出后关闭。
5. 视频导出使用临时文件、关闭编码器、重新打开验证和原子替换的提交顺序。

## 后果

界面保持可响应，同一模型不会被并发调用，取消和关闭过程可验证。代价是每个任务需要重新加载模型，会增加启动延迟和短时内存使用。后续若需复用模型，应使用单一长寿命推理线程和消息队列，不应恢复跨线程共享。
